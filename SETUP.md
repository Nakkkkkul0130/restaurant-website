### 🚀 **Quick Start**

1. **Install Dependencies:**
   ```bash
   install-all.bat
   ```

2. **Start Development (Choose one):**
   ```bash
   # Full stack (both frontend + backend)
   start-dev.bat
   
   # Fast frontend only (recommended for UI work)
   dev-fast.bat
   ```

3. **Access:**
   - Frontend: http://localhost:3000
   - Backend: http://localhost:5000

### 🔧 **Manual Commands**
```bash
# Frontend (fast mode)
cd frontend && npm run dev

# Backend
cd backend && npm run dev
```
